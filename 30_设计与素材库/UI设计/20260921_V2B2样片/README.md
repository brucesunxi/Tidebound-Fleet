# V2-B2：场景与单语言视觉样片

日期：2026-09-21。打开 [index.html](index.html) 查看可操作研究稿，[components.html](components.html) 查看四分类组件板与英文品牌字标方向。浏览器支持 WebGL 即可；无外部库、字体下载或网络依赖。界面外的评审工具采用中文说明，不属于游戏页面。

## 已交付

- 主页：独立港湾背景、两款几何不同的实时3D展示船、可开关的轻摆和接触水纹；无游戏标题、无已通关进度条，左右入口与主操作分层。
- 局内：只读复用 `P5R_Ten_003` 的14×18／80船布局；将B1的轮廓、结构高度和船头箭头移植到浏览器小船模型。仅保留俯视可见部件，材质与渲染管线是浏览器候选，不是Unity运行画面的替代验收。
- 结算：金币、展示船、下一件外观奖励目标、下一关／主页／分享；无海域统计。十关边界示例保持结算，不自动回主页。
- 图鉴：皮肤抽取，拖尾／主页展示船／背景通关获取；五槽只用于出战皮肤。6项列表是状态占位，实际解锁目录、数量及奖励关卡不在本次冻结。
- 单语言：英文／中文各自完整显示。设置内可选择自动、英文、中文；手选仅保存在 `tidebound.b2.language` 浏览器研究稿偏好中，与Unity游戏存档无关。

## 最新语言规则

用户明确纠正：**不是英文下方添加中文。每种语言模式只显示一种语言。**

| 条件 | 结果 |
|---|---|
| 已手动选择英文或中文 | 优先使用并记住该选择 |
| 自动模式，识别为中国地区 | 中文 |
| 自动模式，其他地区或识别失败／未知 | 英文 |
| 设置改回自动 | 重新按地区状态选择 |

研究稿默认地区未知。评审区可模拟“中国地区／其他／未知”；没有调用定位或声称识别了用户真实所在地。系统显示语言不能单独替代所在地判断。真实平台地区适配、设置持久化和完整字符串／字库接入留到Unity C2。英文品牌字标只在独立品牌板与英文分享卡出现；主页不恢复标题。当前系统字体仅用于候选排版。
