# C2 收藏弹窗参考与接入约束

日期：2026-09-21。来源是用户在「继续I5-C收藏与经济系统」任务最后提供的四张效果图，本轮恢复中断的归档工作。原图和校验信息见[参考库](../../../30_设计与素材库/外部参考/20260921_收藏弹窗四稿/README.md)。本文补充C2视觉参考，不变更既定获取方式、存档或经济。

## 可采用的视觉结构

- 奶油白底、圆角金边、航海木牌标题，贝壳／绳索／船舵作为少量装饰；标题和按钮文字仍由本地化文本单独绘制。
- 右上固定关闭按钮，中部独立滚动内容，底部固定四类页签。皮肤页可固定抽奖入口，其余三类显示当前使用状态与真实获取条件。
- 蓝底卡片统一缩略图比例，名称与状态分行。拥有、未拥有、已装备／使用中分别表达；勾选、锁和文字共同传达状态，不能只靠颜色。
- 皮肤／拖尾／展示船以竖卡为参考，背景用横向缩略图和双列候选；小屏根据48×48触区与文本高度调整列数，不机械复刻四列。
- 遮罩拦截后方主页点击，打开弹窗暂停展示船轻摆，关闭恢复。切分类不创建attempt、不触发抽取、不自动装备。

## 工程接入范围

C2复用C1的主页导航与既有收藏、抽奖、保底、五槽和商店服务，负责公共控件、四分类壳、语言设置、主页背景／图标与独立展示船。D1接拖尾、展示船、背景的稳定目录、拥有／使用状态和通关奖励事务；D1之前不能把参考卡片当作已持久解锁的外观。

整张效果图不能作为可操作弹窗贴图。面板边框、标题装饰、页签、锁、勾、卡片与按钮要独立制作或构建，数字、名称、状态、获取说明由运行时提供。图中中文和英文不能同时堆叠；遵循[语言规则](LANGUAGE_POLICY.md)。截图里的空白状态条不作为最终文案。
