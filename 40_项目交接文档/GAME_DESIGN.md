# Tidebound Fleet（潮汐舰队）游戏设计文档

版本：2.3

日期：2026-09-18

阶段：单基础船与皮肤收藏产品规则基线

**一句话定义：**玩家点击固定朝向的船疏通海面船阵，每艘成功驶出的船沿外围航道加入个人皮肤舰队并攻击海怪；胜利获得金币，用于收集和搭配更多船只皮肤。

目标平台为 Android／iOS，发行渠道包括 Google Play／TapTap。游戏采用竖屏、单指操作，核心关卡可离线完成。

v2.0 确立单基础船与皮肤收藏方向；v2.1 调整金币概率与重开规则；v2.2 明确高密度方向疏通及 1×2／1×3 皮肤边界；v2.3 冻结 12×18 正式棋盘、78–82 艘容量和 20.4% 最低空白。皮肤专项规则见[《船只皮肤收集与经济系统设计》](SHIP_SKIN_COLLECTION_ECONOMY.md)。当前 Phase 1–4 代码仍保留部分旧船型和小棋盘结构，须在继续战斗开发前迁移；本文描述目标产品规则，不表示相关代码已经完成。

## 已确定的关键规则

| 事项 | v2.0 规则 |
|---|---|
| 基础船 | 只有 `TF_BASE_SHIP` 一种逻辑；长度是关卡属性，不是船型 |
| 方向 | 仅上、下、左、右；普通点击不能自行选择方向 |
| 受阻 | 尽可能前进，到最近阻挡前停止；绝不退回原位置 |
| 占格 | 宽度 1 格；标准船长 2、长船长 3；取消长度 4；视觉模型不能决定 Grid |
| 出场与入战 | 船尾完全离开棋盘才算出场；完成中央入口融入才算入舰 |
| 攻击 | 每艘船入舰后攻击一次，固定造成 10 点伤害 |
| 皮肤 | 只用于长度 2 标准船；长度 3 长船固定外观；均不改变移动、攻击或 Boss HP |
| 战区展示 | 最多 5 个标准船皮肤席位；长度 3 长船进入固定支援计数，不占第六个收藏席位 |
| 连击 | 任意皮肤连续出船都可续接；5 秒窗口，只强化表现 |
| Boss | 一个海怪，不主动攻击；初始 HP＝本关初始船数×10 |
| 金币 | 首通固定奖励＋战斗金币；通常胜利入账，系统确认死局时可结算已获得部分 |
| 抽取 | 金币单抽／十连；价格随唯一皮肤收藏数分档增加，有概率公示和保底 |
| 防刷 | 收益概率按同皮肤局内占比锁定；当前关每日最多 10 次奖励重开；已通关关卡不可回刷 |
| MVP | 30 关、12×18 正式棋盘、约 80 艘、1 Boss、3 道具、16 个标准船皮肤、5 个装备槽、图鉴、抽取与本地存档 |

# 1. 游戏核心循环

## 1.1 单局流程

1. **进入关卡。** 读取固定船阵及玩家装备快照，为每艘船分配 skinId；根据船数计算 Boss HP。
2. **观察船阵。** 识别船头、方向、长度和阻挡关系。皮肤外观不提供通关优势。
3. **点击船只。** 船沿固定方向直线移动；受阻则停在阻挡前，无阻挡则完整驶出棋盘。
4. **进入航道。** 船沿对应边缘航道前往顶部中央入口，多艘可以同时在航道中。
5. **加入舰队。** 严格按出场序号入舰；相同皮肤合并到同一个战区席位。
6. **攻击海怪。** 每艘船产生一次 10 点攻击；命中时扣血，并把该船金币写入本局待结算账本。
7. **继续疏通。** 棋盘操作、航道和战斗并行，不要求玩家切换模式。
8. **胜利结算。** 棋盘、航道和攻击全部清空且 Boss HP 为 0 后，固定奖励和战斗金币一次性入账。

单局核心为：**观察 → 点击 → 疏通 → 出海 → 聚合 → 炮击 → 再观察。**

## 1.2 局外循环

**通关获得金币 → 抽取／兑换皮肤 → 补齐图鉴 → 配置最多 5 个皮肤 → 进入下一关形成个人舰队。**

皮肤提供收藏目标和视觉表达，不提供解谜或伤害优势。玩家不抽皮肤也可以使用默认白船完成全部关卡。

## 1.3 30 秒核心乐趣

玩家应在 30 秒内理解：**“先让能走的船出去，腾出空间；船出去会变成我的舰队并攻击海怪。”**

| 时间 | 体验 | 玩家理解 |
|---|---|---|
| 0–5 秒 | 7 艘默认白船，一艘高亮 | 点船，船头决定方向 |
| 5–12 秒 | 第一艘出船、沿航道入舰、炮击 | 解谜动作直接产生战斗反馈 |
| 12–22 秒 | 先移开阻挡船，再放出后船 | 需要规划释放顺序 |
| 22–30 秒 | 连续炮击击败 Boss，金币进入结算 | 疏通节奏带来爽感和收藏资源 |

第 1 关是唯一低数量玩法教学。第 2 关直接进入约 80 艘的正式棋盘；胜利后再教学首次免费皮肤抽取，不在第 1 关介绍道具、品质和保底。

## 1.4 卡局、失败与重试

- 无限时、无步数、无体力和生命限制。
- 棋盘仍有船、无移动进行中，且所有船既不能前进一格也不能驶出时判定卡局。
- 卡局时提示可用道具；玩家没有可用道具或明确放弃使用时，可选择“结算已获得金币并重开”。该结算不含首通固定奖励，也不能观看广告翻倍。
- 主动重开但尚未达到卡局时，本局待结算金币失效。强退或进程被关闭也不结算。
- 每次未通关后再次开始当前关都记为一次“当前关重开”；每天前 10 次属于奖励重开额度。达到 10 次后仍可继续重开和通关，但当天不再提供死局部分结算。
- 胜利结算永远有效，不受重开额度影响。通关后自动推进下一关，MVP 不提供返回旧关入口。
- 每次正式开局锁定皮肤分配、各皮肤数量占比和金币随机结果；恢复同一尝试不能通过重进或改变攻击顺序重抽收益。

# 2. 屏幕布局规范

## 2.1 安全矩形

所有比例基于扣除刘海、摄像头孔、状态／导航栏及底部手势区后的游戏安全矩形 S。

| 区域 | 推荐高度 | 约束 |
|---|---:|---|
| 顶部 Boss 战区 | 12%–17% | 随屏幕比例压缩，不超过 20% |
| 中部棋盘与航道 | 68%–74% | 棋盘净区不低于 60% |
| 底部道具区 | 14%–15% | 不超过 20% |
| 中部外围航道 | 每侧厚度≤安全区短边 4% | 不占 Grid，不接收点击 |

棋盘使用正方形逻辑格，完整显示，不滚动、不手势缩放。第 1 关为 4×6；第 2 关起使用 12×18 正式棋盘。四周航道不占 Grid，每侧可见宽度为单格的 0.42–0.48 倍且不超过安全区宽度的 4%。最小验收安全矩形为 360×640 项目逻辑单位，密集棋盘短边单格目标不低于 25。完整比例、点击规则和容量计算见[棋盘布局与容量规划](BOARD_LAYOUT_CAPACITY_PLAN.md)。

## 2.2 内容与优先级

- 顶部：暂停、关卡号、金币、Boss 血条、Boss、最多 5 个皮肤舰队席位、连击条。
- 中部：船阵、轻网格、水面和方向提示。皮肤细节不能降低头尾可读性。
- 边缘：非交互航道、缩略船影和尾迹。
- 底部：移除船、洗牌、方向转换三个道具入口。

信息优先级为：**船头与阻挡关系 > 点击反馈 > Boss 血量和炮击 > 皮肤装饰 > 环境装饰。**

## 2.3 交互安全

- 顶部与底部按钮距安全区边缘至少 8 个逻辑单位。
- 道具点击区至少 48×48，按钮间隔至少 8。
- 船只点击热区使用完整逻辑占格，不使用模型 Bounds；相邻船热区不能重叠，空格默认不吸附邻船。
- 炮弹、Boss 触手和皮肤特效裁剪在顶部区域，不覆盖棋盘船头。
- 广告、暂停、结算和系统覆盖层出现时冻结单局时间，返回后继续剩余进度。

# 3. 基础船与皮肤系统

## 3.1 单一基础船逻辑

所有关卡实例共享：

| 字段 | 规则 |
|---|---|
| logicId | 固定 `TF_BASE_SHIP` |
| width | 固定 1 格 |
| length | 2／3，由关卡实例定义；不再使用长度 4 |
| direction | Up／Down／Left／Right |
| damage | 固定 10 |
| movement | 相同直线移动与阻挡规则 |
| attack cadence | 相同队列节奏 |

长度仅制造不同的阻挡关系，不代表快艇、战舰或品质。长度 2 为可换皮标准船；长度 3 为固定外观长船。两者移动、伤害和攻击次数一致。Boss HP 按船数计算，不按长度计算。

## 3.2 船实例

关卡静态实例保存 `id、position、direction、length`。进入关卡后追加只读的本局 `skinId`：

```text
ShipRuntime = BaseShipData + skinId + runtimeState
```

正式关卡 JSON 不预写随机 skinId。长度 2 船在开局从装备池获得 skinId；长度 3 船强制使用不可收集的 `TF_LONG_DEFAULT`。分配后，洗牌、方向转换、救援、移动和航道都必须保留该实例的 skinId。

## 3.3 皮肤作用边界

可收集皮肤只作用于长度 2 标准船，并决定：

- 统一 1×2 船体模型。
- 船身材质、主题配色、尾迹、炮口和命中特效。
- 卡面、名称、品质、获取方式和收藏顺序。
- 本局按皮肤数量占比决定的金币概率表现。

长度 3 长船使用一套固定基础模型、固定炮击表现和每次 1 金币，不进入皮肤抽取、装备或图鉴总数。

皮肤不决定：

- 长度、方向、移动能力、占格、碰撞、伤害或攻击次数。
- Boss 血量、关卡解法、道具效果或胜负条件。

## 3.4 品质、装备与分配

- 品质为白、蓝、紫、金、红；获取概率依次降低。
- 默认白船永久拥有。玩家最多装备 5 个不同皮肤；空装备池全部回退默认白船。
- 红色皮肤允许单独装备，不设置品质歧视性限制。
- 一局的可收集皮肤数量不超过 5。平衡洗牌袋只分配长度 2 标准船；船数足够时每个装备皮肤至少出现一次，各皮肤数量差不超过 1。长度 3 长船不参与分配。
- 同一 attempt 恢复时保留分配；正式重开创建新 attempt 并计入每日记录。皮肤不会标记关键船或改变难度。

详细抽取、装备、收益和存档规则见[专项设计](SHIP_SKIN_COLLECTION_ECONOMY.md)。

## 3.5 美术识别规范

- 所有皮肤船头偏尖、船尾偏宽；关键轮廓不能依赖颜色。
- 方向三角与船体朝向一致，属于统一玩法层，不被皮肤遮挡。
- 所有可收集皮肤只需制作统一 1×2 规格；禁止通过拉伸皮肤资产生成长船。
- 1×3 长船必须保持固定且明显不同的基础轮廓，同时沿用同一套方向标和头尾规范。
- 白、蓝、紫、金、红是卡面品质语言，不要求船身全部使用对应颜色。
- 灰度和低亮度下仍能分辨头尾；强发光皮肤必须有简化特效版本。

# 4. 挪船规则

## 4.1 坐标与占格

- 原点在棋盘左下角，x 向右、y 向上。
- `position` 永远表示船尾格。
- 从船尾沿 direction 连续占据 length 个格子。
- 移动判断只依赖整数 Grid，不读取 Transform、Renderer、Collider 或皮肤模型尺寸。

例：长度 3、船尾 (1,2)、方向 Right，占据 (1,2)、(2,2)、(3,2)，从 (4,2) 开始检查阻挡。

## 4.2 点击结果

1. 只允许沿当前方向移动。
2. 路径无遮挡时，船继续行驶，直到船尾完全离开棋盘。
3. 路径有船阻挡时，移动到最近阻挡前的最后合法位置。
4. 紧邻阻挡时位移为 0，只播放轻撞反馈。
5. 受阻后新位置成为正式位置，不返回原点。

禁止斜向移动、普通拖拽、推动其他船、穿越占格、碰撞扣资源或自动撤销。

## 4.3 时序

- MVP 同时只执行一艘棋盘船移动；额外点击返回 Busy，不缓存。
- 有效移动参考 12 格／秒，单次 0.18–0.60 秒。
- 零位移或停稳后反馈约 0.12 秒。
- 船尾完整离界前不释放占格；完成后一次性释放、分配 ExitSequence、进入 InLane。
- 航道和战斗运行时不锁静止棋盘。

# 5. 航道系统

流程：**棋盘 → 对应边缘接入口 → 外围航道 → 顶部中央入口 → 对应皮肤舰队席位。**

| 离开边 | 路线 |
|---|---|
| 上 | 沿上边框前往中央入口 |
| 左 | 沿左侧向上，经左上角进入中央 |
| 右 | 沿右侧向上，经右上角进入中央 |
| 下 | 选择到左右底角较短路线；等距走右侧 |

- 船尾完整离界时取得递增 ExitSequence。
- 多船可并行航行；每船名义航行 1.20 秒，长路线以更高表现速度补偿。
- 中央入口严格按 ExitSequence FIFO。后船先到必须等待。
- 入口最小间隔 0.15 秒，融入席位统一 0.15 秒。
- 暂停冻结路径、等待和融入进度；恢复后不跳时、不重复入舰。
- 重试销毁旧 Session 的航道和事件；旧船不能进入新关卡。

# 6. 战斗系统

## 6.1 聚合展示

- 每个长度 2 标准船 skinId 最多创建一个常驻代表船，最多 5 个收藏皮肤席位。
- 首艘入舰建立席位，之后同皮肤只增加累计数量和待攻击次数。
- 席位按装备槽顺序固定；默认回退船排第一。
- 入场临时船影结束后隐藏，不形成重复常驻模型。
- 长度 3 长船不创建第六个皮肤席位；它进入固定支援计数，并在抵达中央入口时使用统一长船炮击表现。

## 6.2 每船一次攻击

- 每个 `ShipEnterFleetEvent` 产生一个 AttackToken。
- 每个 AttackToken 固定伤害 10，必定命中，无暴击、护甲、闪避、元素或随机伤害。
- 同皮肤攻击按 ExitSequence 排队，启动间隔 0.20 秒；不同皮肤可以并行。
- 发射至命中参考 0.25 秒。皮肤可以改变炮弹、音效和命中表现，不改变结算时点。
- 入舰和发射不扣血；命中时去重扣血一次，并记录一次战斗金币。
- 常驻代表船没有周期自动射击，待攻击队列清空后停止。

## 6.3 Boss HP 与胜利

```text
Boss InitialHp = 关卡初始船数 × 10
```

HP 在关卡加载时计算一次。洗牌、救援、皮肤品质、装备变化或船离场不会重算。

胜利必须同时满足：

1. 当前棋盘船数为 0。
2. 航道与入口等待数为 0。
3. 待发和飞行攻击数为 0。
4. Boss HP 为 0。

正常关卡全部船出海必定胜利。Boss 提前死亡或全部攻击结束仍有 HP 都视为配置／事件错误，不能要求玩家看广告补伤害。

# 7. 连击、金币与收藏成长

## 7.1 连击

- 船尾完整离场时建立或续接 5.0 秒连击，与皮肤品质无关。
- 1–2 次为 I，3–5 次为 II，6–9 次为 III，10 次以上为 IV。
- 连击只提升拖尾、炮击、音效和轻震动，不改变伤害、金币或攻击次数。
- 暂停、后台和广告冻结计时；普通观察与道具选择不冻结。

## 7.2 战斗金币

白色皮肤每次命中固定产生 1 金币。蓝、紫、金、红每次命中分别在 `1–2、1–3、1–5、1–8` 之间产生整数金币。

设本关可换皮的长度 2 标准船总数为 `E`，某个 skinId 分配到 `n` 艘，该皮肤占比 `q=n/E`。长度 3 长船固定产生 1 金币，既不参加随机收益，也不进入 E。标准船每一枚额外金币的独立成功概率为：

```text
p = clamp(0.10 + 0.875 × (1 - q), 0.10, 0.80)
单船金币 = 1 + Binomial(品质上限 - 1, p)
```

概率在正式开局时按分配快照锁定，不会随着船驶出而变化。单独装备一种皮肤时 `q=100%`、`p=10%`，收益明显偏向 1；五种皮肤完全均衡时 `q=20%`、`p=80%`，每种皮肤更容易接近品质上限。第 2 关的 80 艘标准船分给五种皮肤时为每种 16 艘。红色皮肤仍可单独装备，不设置槽位限制。

以第 2 关 80 艘标准船全部使用红色皮肤为例，每船期望金币为 `1＋7×10%=1.7`，整局期望约 136，实际范围为 80–640；达到单船 8 金币的概率仅为 `0.1⁷=0.00001%`，全局 640 金币的概率约为 `10⁻⁵⁶⁰`。五种皮肤完全均衡时，红色单船期望为 6.6，达到 8 金币的概率约 20.97%。这样既保留稀有皮肤的惊喜，也鼓励收集并搭配多个不同皮肤。

攻击命中后金币只写入 PendingBattleCoins。正常胜利统一入账；系统确认死局且玩家选择放弃道具并重开时，可以结算已经命中的部分金币。

## 7.3 首通、当前关重开与广告

- 第 n 关首通固定奖励为 `100＋20×(n−1)`；30 关固定奖励合计 11,700。
- 首次胜利另获完整战斗金币，不受当日重开次数影响；胜利后自动进入下一关，不能返回已通关关卡刷币。
- 当前未通关关卡每天前 10 次重开记为奖励重开额度。非死局主动重开只记录次数，不结算本局金币；确认死局选择结算并重开时，消耗一次额度并结算已获得金币。
- 第 11 次及以后仍可自由重开、使用道具和通关，但当天不再提供死局部分结算。最终胜利仍正常发放战斗金币与首通奖励。
- 第 3 关后每天可主动观看 1 次激励广告免费单抽。
- 每天最多 3 次胜利结算可通过激励广告把战斗金币翻倍；首通固定奖励不翻倍。
- 死局部分结算不能广告翻倍。广告失败、取消、无填充或重复回调不扣机会、不阻断原结算。

## 7.4 抽取、装备和图鉴摘要

- 抽取池为 15 个皮肤，加默认白船共 16 个 MVP 皮肤。
- 基础概率：白 48%、蓝 30%、紫 15%、金 6%、红 1%。
- 第 2 关后免费首抽，必出未拥有蓝皮；十连价格为单抽 9 倍，至少出现一个紫色以上。
- 20 抽无金色以上则保底金色以上；60 抽无红色则保底红色。
- 重复皮肤转换收藏券，用于定向兑换未拥有皮肤，不提升属性。
- 单抽价格按已拥有的非默认唯一皮肤数 U 分档：300、450、700、1,000、1,400、1,800、2,200。
- 最多装备 5 个皮肤；一局按装备池平衡随机，战区按 skinId 聚合。

完整价格表、重复兑换、保底优先级和验收见[专项设计](SHIP_SKIN_COLLECTION_ECONOMY.md)。

# 8. Boss 系统

MVP 只有一个 Boss：

| 字段 | 规则 |
|---|---|
| bossId | `TF_KRAKEN_01` |
| 名称 | 深海克拉肯 |
| 初始 HP | 初始船数×10 |
| 主动攻击 | 不启用 |
| 受击 | 固定伤害、必定命中、无无敌、护甲或回血 |
| 死亡 | 所有攻击完成且 HP 为 0 后播放约 1 秒死亡表现 |

表现阶段：HP>70% 为挑衅；30%<HP≤70% 为受压；0<HP≤30% 为濒败；HP=0 为死亡。阶段只改变表情、触手和受击强度，不改变玩法。

# 9. 道具系统

三个道具均为单局次数，不进入跨关背包：

| 道具 | toolId | 免费次数 | 规则 |
|---|---|---:|---|
| 移除船 | `TF_TOOL_RESCUE` | 1 | 拖离目标并从最近边缘进入航道；保留 skinId、攻击和金币 |
| 洗牌 | `TF_TOOL_SHUFFLE` | 1 | 重排剩余实例的位置和方向；保留 id、length、skinId；结果必须合法可解 |
| 方向转换 | `TF_TOOL_REVERSE` | 1 | 当前方向旋转 180°；占格必须仍合法；不自动移动 |

- 第 1 关不展示道具。第 2 关保持纯正式棋盘；第 3 关起按首次使用场景开放道具轻提示，不再设置低数量教学关。
- 进入目标选择不消耗；效果成功落实时才扣次数。
- 道具只作用于仍在棋盘的船。棋盘移动中暂时不可用，航道和战斗运行时可用。
- 库存为 0 时可主动看激励广告补充 1 次；每关每种最多成功补充 1 次。
- 广告不是通关前置；失败时仍可不看广告直接重开，重开按第 7.3 节记录。

## 10.5 体验与技术验收

- 至少 4/5 名首次玩家在 30 秒内完成一次出船并说出“出船会攻击海怪”。
- 1×2 标准船和固定 1×3 长船在四方向和灰度状态下均能正确识别头尾；至少 4/5 测试者准确率达到 90%。
- 80 艘船和 5 种标准船皮肤同时出现时，棋盘仍先读出方向与阻挡，不因颜色、粒子或模型留白误判。
- 三种目标手机比例满足顶部≤20%、棋盘净区≥60%、航道≤5%、底部≤20%。
- 目标 60 FPS；最低验收设备不得持续低于 30 FPS 超过 1 秒。Android 最低测试内存 4 GB，iOS 3 GB。
- 连续推进与重开 30 局无崩溃、输入锁、重复入舰、重复伤害、重复金币或持续对象累积。
- 存档损坏时保留关卡安全回退入口，并使用默认白船；不得因皮肤数据问题无法开始游戏。
