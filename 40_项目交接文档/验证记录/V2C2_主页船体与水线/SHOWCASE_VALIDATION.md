# C2主页展示船：曲面、材质与水线

2026-09-21。继续上一轮主页立体按钮修正，本轮只改善主页独立展示船。C2视觉仍开放，D1未启动。

## 已实施

- 船壳和屋顶采用多段平滑曲面；缩放围绕各部件自身中心，避免偏心船舱和屋顶被拉歪。加宽展示船横向比例，调整取景和中心，保留旗帜顶部安全余量。
- 窗框有圆角和厚度，玻璃采用独立亮度渐变与反射带；金色构件、船体漆面和玻璃使用不同金属度／粗糙度参数。光照与正交观察方向不依赖预览对象被隔离到的远处世界坐标。
- 改善驾驶舱、金色栏杆、甲板台阶、救生圈、烟囱和旗帜位置，仍为实际Mesh，不将参考图或静态船图片充作3D模型。
- 新增一张小型船底平面及透明水线shader，提供船底接触暗部和断续亮纹。第一版外围圈过大，已贴近船底水线，不采用持续扩大光环。
- 水纹使用预览自己的时间；减弱动效／AllowMotion关闭时不推进，隐藏主页后停止更新。水面材质、网格和RenderTexture随预览释放。主页640×640 RenderTexture请求4×MSAA，仍需目标设备确认支持与成本；收藏详情保持原192尺寸。
- 无游戏物理、Collider、Grid、局内模型、钱包、皮肤身份或存档变更。主页当前尚未接入D1的可选展示船目录，这个默认模型不代表新增拥有奖励。

## 验证

最终隔离Unity PlayMode **17/17通过**：主页导航9项、C2 UI 6项、展示船2项。新增检查覆盖所有船体顶点位于预览取景范围、材质参数区分、单位法线、顶点数上限、私有渲染层及无Collider；动效关闭／隐藏时水纹冻结、恢复后推进；销毁后材质、网格和RenderTexture全部释放。初轮测试实际发现旗帜边缘贴框，修正后通过；Metal shader编译错误已修正，最终运行日志未出现shader／C#编译错误。

本轮未重跑全量EditMode、未做移动端构建或真机性能测试，不沿用历史测试数量冒充本轮通过。顶点数断言仅为资源规模约束，不等于移动设备性能通过。

已检查英文／中文360×640与390×844实际Game View，另外保留关闭水线对照。短动图由28帧实际运行截图按真实时间间隔编码，包含船体／水线变化和一次主按钮按下／放开；没有触发Click，没有更改用户真实档案。GIF使用原生ImageIO编码，颜色会因GIF调色板产生量化，应以PNG评估静态细节。完整哈希与用例见[TEST_SUMMARY.json](TEST_SUMMARY.json)。
