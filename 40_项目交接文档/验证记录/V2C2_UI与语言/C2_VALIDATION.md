# V2-C2：公共UI与单语言最小接入

日期：2026-09-21。本轮是可玩工程接入与界面适配，不是终版美术或移动端发布验收。

## 已实现

- 主页导入独立港湾背景及收藏／抽奖／补给／每日奖励／邀请／排行6张透明图标。背景按屏幕比例裁切，按钮和文本为独立控件；继续不显示游戏标题、主页券数、通关条及换船箭头。
- 主页独立RenderTexture船体预览，透明背景、斜角视图和轻摆；设置／其他弹窗、后台及减弱动效时停止。预览与收藏相机使用隔离的空间位置；不读取模型尺寸决定Grid，也不改变当前attempt的皮肤。
- 公共圆角面板与按钮由UI网格绘制，可随尺寸伸缩；收藏／补给采用奶油底、木色标题板、青色卡片与固定关闭／分类／底部导航。中部内容使用ScrollRect与RectMask2D，小屏滚动而不压缩按钮触区。
- 收藏保留原16皮肤目录、5槽、筛选、分页、兑换与真实拥有状态。皮肤／拖尾／形象／场景四类入口已接；后三类显示通关获取与目录待配置说明，没有虚构拥有、切换或奖励。皮肤缩略图是共享程序示意，不是16款最终皮肤素材。
- 独立抽奖页复用既有单抽、十连、首蓝赠送、概率／保底说明和保存后揭示；首蓝待领取时按钮优先显示。交易确认期间不允许分类导航，重复确认仍复用原请求身份。金币价格和保底计数全部由现有服务计算。
- 补给页显示现有4商品及实时库存／金币，保留确认、保存失败、重复回调处理；广告和真钱礼包仍禁用。图鉴、抽奖与补给可互相导航，购买不自动用道具。
- 主页、设置、收藏、交易、商店、主要HUD、入场、死局与胜利文本接入统一语言文本组件。使用英文源消息键和参数化中文词表；组件保存源消息，切换或重新启用时刷新，不对翻译结果再次翻译。稳定皮肤ID如B-01保留为标识。
- 语言偏好Auto／English／Chinese单独写PlayerPrefs，不改变v4档案。手选优先，首次呈现前解析地区；中文与英文单语言显示。完整Noto Sans CJK SC字体随工程打包，OFL许可与来源记录同行，不依赖开发机系统字体。

## 地区与平台边界

Android适配尝试读取TelephonyManager的当前网络国家码；CN对应中文，其他二字母国家码对应英文；无电话服务、空值、格式异常或调用失败均回退Unknown／英文。未新增定位权限、外部IP服务、广告／支付SDK。未连接Android设备验证这条平台分支，不宣称真实地区识别验收通过。

iOS与桌面目前没有经验证的离线当前位置来源，返回Unknown，首次为英文，用户可手动选中文。不把设备语言、时区、SIM发行国或设备设置中的地区冒充当前位置。iOS自动地区提供器仍为后续平台适配项。

## 明确保留的工作

主页展示船仍复用程序模型，卡面为程序缩略图；它们是接入占位，不能替代用户目标图的精修船体、图标、边框装饰与完整正式美术。当前只导入此前已生成的港湾和6功能图标，两张新参考整图没有导入运行时。

D1继续三类通关外观目录、持久拥有／使用与去重发奖；解锁表需先形成具体候选。D2接真实奖励目标及分享，V2-E接完整动效／音效。局内船体、Boss与结算小船仍含灰盒元素。30关量产、真实广告支付与排名后台没有提前实施。

存档schema、钱包公式、抽奖概率／价格、五次额度、道具规则、原10关与Grid逻辑未更改。原有未提交Plugins与UI设计交接文档保留；原Resources/TideboundUI目录元数据由本轮资源接入复用。
