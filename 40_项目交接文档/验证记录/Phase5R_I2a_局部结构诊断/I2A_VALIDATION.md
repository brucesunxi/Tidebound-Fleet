# Phase 5R I2a：局部结构诊断

日期：2026-09-19。结论：T-P04a的诊断实现与对照测试完成；产品筛选阈值仍待十关候选比较及体验校准。本轮不是I2整体完成，没有新增或批准关卡，没有进入战斗。

## 改动与入口

- `Runtime/Core/LevelDesign/LocalLayoutAnalyzer.cs`：独立纯C#诊断器；读取不可变Board快照，不引用Unity，不修改占格、方向或移动规则，也不改变现有生成器的排序／结果。
- `Editor/LevelStudio/LocalLayoutDiagnostics.cs`：诊断文字及I1样关审计导出。
- Level Studio新增`Local Layout Diagnostics`按钮及可选分析范围。编辑态分析当前布局；试玩态分析当前剩余棋盘。编辑、移动、重开或范围变化清除旧结果，点击按钮重新计算。默认全棋盘；教程可勾选Custom area并使用X=4、Y=5、Width=6、Height=8。
- 编辑器导出：`Tools > Tidebound > Export I1 Local Layout Audit`；batchmode入口`Tidebound.EditorTools.LocalLayoutDiagnostics.ExportI1Baseline`。导出到系统临时目录，不修改原样关。本次实际导出报告已归档为[I1_LAYOUT_BASELINE.md](I1_LAYOUT_BASELINE.md)。

## 指标定义

分析版本为`LocalLayoutV1`。所有坐标为逻辑Grid、左下原点、从0计数；这里不推断屏幕触控质量。

| 指标 | 明确定义 |
|---|---|
| 同向连续船列 | 沿每行／列扫描方向相同的不同船；同船占2／3格只计一次；不同方向中断；记录最长序列起止格和船ID |
| 跨空格船列 | 同上，但相邻两个占格段之间允许最多1格空白；不是整个序列总共只能有1格空白 |
| 局部方向混合 | 范围内完整4×4滑动窗口、步长1；每艘与窗口相交的船计一次，包含仅部分足迹进入窗口的船；熵按四方向归一到0～1 |
| 覆盖与分位数 | 至少4艘的窗口才计熵；空窗／稀疏窗分开报告，无合格窗口返回N/A；P10采用最近秩`ceil(0.1×n)` |
| 最大空矩形 | 范围内完全无占格的最大轴对齐矩形；记录位置、宽高和面积；无空格面积为0 |
| 分区占用率 | 对分析区作四分；奇数尺寸左／下取floor，右／上承接余数；窄板省略零面积区，保持总面积与占格不重不漏 |

窗口、最小船数和允许空隙均可由纯逻辑API传入。编辑器本轮使用4×4／4艘／1格的固定诊断参数；只将分析范围暴露给界面。非法参数显式拒绝，不静默裁剪或修改输入。

## 实测发现

| 样本／分析范围 | 最长连续行／列（艘） | 最长跨1格行／列（艘） | 最低局部熵／P10 | 最大空矩形 | 合格／总窗口 |
|---|---:|---:|---:|---|---:|
| I1 7船，全14×18 | 1／2 | 2／2 | 0.4056／0.4056 | (0,0)，5×18=90格 | 9／165 |
| I1 7船，中央6×8 | 1／2 | 2／2 | 0.4056／0.4056 | (8,5)，2×6=12格 | 8／15 |
| I1 80船，全14×18 | 6／3 | 6／3 | 0.0000／0.4316 | (1,1)，2×5=10格 | 157／165 |

80船的6艘连续左向船位于y=9、x=2～13：S077、S065、S049、S040、S035、S031。最低混合窗口在(6,4)，尺寸4×4。说明原全局方向熵约0.9941及相邻同向率约0.4727未能充分揭示局部排列，下一步应调整生成候选排序并据此比较。

教学关全棋盘的90格空矩形主要是预留水面，不能沿用80船的筛选条件直接拒绝。范围调整后仍保留真实坐标；分析区不是移动墙，也不改变船的出口。

对照测试另造两个8×8、32船的空间夹具：两者四方向总量均衡、全局熵均为1；同向四分区最低局部熵／P10为0，交错排列均约0.9591。它们用于验证诊断能力，**不是已求解或批准的玩法样关**，没有写进正式关卡目录。

目前不把0.9591或某个船列长度设为全游戏硬阈值。还需在可解的密集候选、不同配方与真人识别数据上校准；这里的诊断不会自动批准／拒绝关卡，也不会为了通过指标修改船数。
