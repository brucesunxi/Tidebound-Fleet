# 长期收藏：封顶抽价、扩池、拖尾与船形象

日期：2026-09-24。状态：用户要求下的设计方案与离线预算，尚未写入正式游戏。**最新收益口径：白船每船1金币，红船概率1～8金币；胜利另给固定约100，死局退出／重开不给通关奖。普通80白船关约180总金币，高品质混合舰队平均约400作为预算参照，不是硬上限。**沿用单抽、必得未拥有完整外观；没有十连、重复券、碎片、兑换或保底。本文为本轮最新方案，覆盖旧审查的单次10000／13000／16500与旧三类固定价格建议。

## 1. 长期统一规则

1. **单抽必得未拥有的完整物品。**每次成功保存后揭示结果，抽前只从已发布、已开放、未拥有、符合品质门槛的物品里选择。
2. **金币共用，各池独立计次与报价。**只计该池成功完成的付费单抽；免费首蓝、通关／分享赠送和失败交易不涨价，也不推进本方案的付费抽数门槛。
3. **价格逐步增加，最高7500。**达到上限后第20、50、100抽都仍是7500，不按新增物品数继续上涨。
4. **扩池不重置。**保留已拥有物品、成功付费次数和已开放的金／红资格。便宜的前几抽是新玩家入门曲线，不是每次更新可重新购买的折扣。
5. **当前可抽内容集齐则停止扣费。**全部已发布内容集齐显示“当前奖池已集齐”；若还有公开章节锁定的新内容，显示“本阶段已集齐／第X关开放下一批”，不能把锁定内容伪装成已拥有。
6. **新内容沿用稳定ID与渠道。**通关、分享专属不混入池。新增候选或图片不等于正式可抽资源；有真实资源、权益映射、获取记录、应用表现和验证后才能发布。

旧版十连／券回执继续用旧算法校验；新计价版本的初始承接应专项验证，不能把旧十连历史直接当新版高额抽数，也不能清零旧权益。一次规则迁移与正常内容扩充必须区分，正常扩池永不重置价格与资格。

## 3. 品质、概率与开放门槛

| 奖池 | 当前／建议随机品质数量 | 金色从第几次付费抽取可出 | 红色从第几次可出 |
|---|---|---:|---:|

使用一套基础品质权重：白48、蓝30、紫15、金6、红1。未开放或已无未拥有物品的品质权重为0；对剩余权重归一化，抽中品质后在该品质未拥有物品里等概率选择。这些是权重，不是永远不变的百分比。规则页显示当次真实品质／单款概率；主界面只说明单抽必得新物品、尚未开放的品质和当前价格。

当前小池的自然边界：船皮首金在第6～8次、首红在第10～11次；船形象亦如此。拖尾首金可能在第3～5次，首红在第4～5次（第4次抽红会使金留到第5次）。这是有限物品且不重复的结果，不是另外的保底。拖尾只有5款，刻意复制第10抽红的门槛会造成无可抽内容，不能套用。

这些“最迟第几次”只适用于当前数量，未来增加低品质物品后不再成立；仍保留开放门槛，不宣传永久保证某抽首次出金／红。已到门槛的老玩家扩池后不重新锁金红。

发布校验应确保任何支持的正常进度都不会出现“未达到付费次数门槛，又没有能抽的物品，无法推进次数”的闭锁。迁移档案需保留已取得的开放资格；公开的章节锁定则可以暂时停止抽取，但必须说明开放条件。

## 6. 扩池及长期收益

### 扩池如何继续

例如某玩家已抽完首批船皮13次，后续新增5款真正进入同一个池，则下一抽仍7500，集齐这5款最多37500；不会再从200起步，也不会抽回已拥有旧船。旧金／红资格保留。新增只有红品质时，对已开放红的玩家，条件红色概率就是100%，不得仍标1%。

更新内容应有清晰的可见获得方式。可按新海域发布一批，并给新条目公开章节门槛；不倒锁旧内容、重置计数或为了消耗老玩家存款临时提价。有存款的老玩家快速拿到新外观是储蓄的正常价值，不应靠回收金币或假概率阻止。

### 用户最新明确的金币口径

| 项目 | 当前设计口径 |
|---|---|
| 白船战斗金币 | 每船固定1；80船局约80 |
| 红船战斗金币 | 每船按概率产出1～8，不改成固定5或最高5 |
| 其他品质 | 当前代码蓝1～2、紫1～3、金1～5；本轮未要求改这些范围 |
| 胜利奖励 | 固定约100，与关号无关；同一笔胜利只结算一次 |
| 死局退出／重开 | 不发这100通关奖；本条不等于新授权修改已产生战斗金币的原部分结算规则 |
| 恢复或重复回调 | 不伪造胜利、不重复发通关奖；普通退出恢复仍延续原attempt |
| 80白船通关总额 | 约80＋100＝180 |
| 高品质混合舰队总额 | 平均约400作为预算参照，含固定100；实际随皮肤构成和随机结果波动，可以高于400 |

**撤回此前2080首通封顶、单关两千多金币及据此第65／96关集齐的推演。**也不使用中间把红船视为固定5／最高5金币的口径，不另叠加随关号增长的通关奖。固定100是本次最新补充，与船战斗金币分别显示、胜利时合并结算。

当前代码仍是旧`100+20×(关号−1)`首通规则，尚未实现上述修改。船战斗金币已是概率范围；本次主要收益规则变更是固定胜利奖，不能为调整它而清空旧钱包或破坏历史回执。须新收益版本、旧账本按旧算法、活动attempt沿用开局规则。

### 400金币参照的交叉核对

现有概率还取决于同皮肤在标准船中的占比，不只看品质。采用第55关的76标准船＋4长船结构，并将胜利奖改为100后，按现有战斗公式的数学期望：

| 假设装备分配 | 期望单关总金币 |
|---|---:|
| 全白 | 180.00 |
| 只装备一种红船 | 233.20 |
| 紫／金／红三种均分（26／25／25标准船） | 404.11 |
| 三种红船均分 | 543.48 |
| 三红两金五种均分 | 532.57 |

因此高品质混合约400是合理的典型预算参照，但不能宣称所有高品质组合平均都恰好400。表格是现有概率公式＋候选固定100的期望，不是当前游戏实际已改成100，也不是实测一局结果。拖尾和主页船形象品质不改变这些战斗收益。

## 7. 固定收益下的长期预算

以标准80船胜利的总收入作敏感性分析；180对应全白，400为高品质混合参照，260／340为中间测试档位，不是已冻结的平均配装。最高7500是后期目标，并非前期每次都收7500。

| 单关总收入 | 从零攒7500、无其他支出 | 每关另预留75道具支出后 |
|---:|---:|---:|
| 180 | 42关收益 | 72关收益 |
| 260 | 29关收益 | 41关收益 |
| 340 | 23关收益 | 29关收益 |
| 400 | 19关收益 | 24关收益 |

这不是“在第几关拿到某物品”的预测。初始钱包、免费赠送、实际道具需求、关卡未通过、配装增长和其他池竞争均影响实际进度，不能把收益当量当玩家必然完成时间。

当前三池合计100200金币，在恒定400总收入且不买道具的极简情景，约等于251次标准通关收入；每关75道具预算则约309次。**目标改为跨数百关逐步收藏，不要求100关收齐三个池。**便宜的入门抽取和通关专属提供前期反馈；拖尾当前5件7900保持较短收藏周期，船皮和船形象为较长目标。若7500阶段的实际等待过长，应根据真实抽取间隔调整曲线／上限，不通过加回高额通关奖励掩盖问题。

已读取真实100关7927船做预算筛查：固定100胜利奖不按教学船数缩放，战斗部分按每关船数缩放；不模拟失败战斗币或额外奖励。三池优先购买较便宜的下一抽、每关75道具预算、保留650余额时：180收入情景百关付费抽取为船皮6／拖尾3／形象3；400情景为船皮8／拖尾5／形象6，船皮另含免费首蓝。不是完整逐船暴击模拟或真实玩家行为。

后续新增内容供给也应收敛：若每100关净收藏预算约18500～32500（260～400总收入减75道具预算），封顶价约支持2～4件新增随机外观，三池合计。可把每新增100关2～4款随机内容作为产能／预算讨论起点，通关专属另计；不延续此前每50关8～12款的高收入假设，也不宣称更新内容已经制作。允许储蓄和暂未集齐，不为消耗存款添加重复奖。

设计模型对每池3000个合成档案验证品质过滤与不重复，首批无空池闭锁；价格连续1000个计次不超过7500；假设扩充5款后保留计数／资格，总价37500。它们不是Unity运行时验收，也没有制作101关以后内容。
